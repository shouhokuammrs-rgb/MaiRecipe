# DEC-037: 取り込んだレシピを、まとめて読み直せる

- Status: Accepted
- Date: 2026-11-18
- 決めた人: Eiichi（「機能改善中なので、最新の機能でもう一度読み返したいことが多々ある」）
- 関連: DEC-022（裏で進める取り込み）

## 決定
- 設定 →「まとめて読み直す」。出典のあるレシピが並び（はじめは全部選んである）、選んだ分を順番待ちに入れる
- 裏で2件ずつ進める（AI の無料枠と相手のサイトにやさしく）。1件終わると次が始まるので、アプリを閉じても進む。順番待ちは `import_jobs.status = queued`
- 勝手には保存しない。読めた結果は今までどおり「確かめる」→ 保存で新しい版（前の版は残る）
- 読み直した内容（題名・材料・手順）が今までのどれかの版と同じなら、確かめる一覧に出さずに消す。変わったものだけ見ればよい
- 読む URL は保存してある出典だけ（クライアントから受け取るのはレシピの id）。同じレシピを二重に待ちに入れない。待ちは200件まで。「残りをやめる」で止められる

## 選ばなかった案
- 読み直した結果をそのまま保存する → 手で直したレシピが上書きされたように見える。確かめてから保存のまま
- 画面を開いている間だけ順に読む → 閉じると止まる

## 影響
- AI の1日の枠に当たると、残りの動画は「読み取れませんでした」になる。次の日にもう一度読み直す
- 確かめる一覧に出るのは新しい順に20件・1日以内（DEC-022 のまま）。たくさん変わったときは、確かめながら進める
