# DEC-010: 自分が使いたい機能は足してよい。将来はレシピ SNS を目指す

- Status: Accepted
- Date: 2026-09-28
- 決めた人: Eiichi
- 関連: DEC-002（この決定により Superseded）/ docs/spec.md §1〜§4

## 背景
デモですり合わせる中で、レピッタにない機能（改良のあゆみ、材料から探す、買い物の期間指定など）が欲しくなった。
アプリの方向性が見えてきて、将来はレシピを投稿・アレンジし合える SNS にしたいという構想ができた。

## 決定
- 「レピッタにある機能か」ではなく「自分（と一緒に使う人）が使いたいか」で採用を決める
- 基本の流れは「探して取り込む → 自分好みに改良 → 献立 → 買い物」。ゼロから作るのは補助（公開時はプレミアム機能）
- SNS は今は作らない。データに「作った人（author_id）」と「公開 / 非公開（visibility）」の欄だけ先に持っておく

## 影響
- 採用基準が変わるので、Issue を足すときは spec.md §3 を更新する
- SNS に進むときは、公開ルール（DEC-011）・サーバー構成・費用・ログインを改めて見直す
