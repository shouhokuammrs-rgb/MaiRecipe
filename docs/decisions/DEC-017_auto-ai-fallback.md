# DEC-017: 取り込みで規則が読めなかったら、押さなくても自動で AI（無料）に回す

- Status: Accepted
- Date: 2026-10-19
- 決めた人: Eiichi
- 関連: DEC-012（一部を変更）/ DEC-016 / Issue #36

## 背景
DEC-012 は「AI は押した時だけ」と決めた。費用と、何をしたか分かりにくいことが理由だった。
「AI で読み取る」は Workers AI の無料枠（DEC-016）で動き、ふたりで使う分には費用がかからない。
押す手間をなくしたい。一方で、規則で読めるページは規則のほうが正確で速い（0.5 秒。AI は 10〜30 秒で、まれに分量を書き間違える）。

## 決定
- URL の取り込みは、まず規則（AI なし）で読む
- 材料か手順が 0 のとき（読めなかった・一部だけ読めた）だけ、自動で AI（無料）に回す
- AI のほうが多く読めたら AI の結果を使い、そう分かる文言（「AI（無料）で読み取りました」）と、元の文に無い材料の「要確認」を出す
- AI が使えないとき（無料枠切れ・不通）は、規則の結果に理由を添えて返す
- **DEC-012 の「押した時だけ」は、費用がかかる AI（Claude・Gemini の有料分）には引き続き当てはめる**。無料の Workers AI の読み取りだけ例外

## 影響
- 読めないページの取り込みは 10〜30 秒かかることがある（画面に目安を出す）
- 一般公開するときは、無料枠が全員で共有になるので見直す（有料プランの機能にするか、押した時だけに戻す）
