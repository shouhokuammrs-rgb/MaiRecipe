# DEC-036: 手順に出てくる材料に、分量を添えて見せる

- Status: Accepted
- Date: 2026-11-18
- 決めた人: Eiichi（「手順に『塩を』『片栗粉を』とあるのに分量が載っていない。手順にも分量があると見やすい」）

## 決定
- 手順の文に材料の名前が出てきたら、材料表の分量をかっこで添える：「塩をふる」→「塩（小さじ1/2）をふる」。まとまりは「A（しょうゆ 大さじ1・みりん 大さじ2）」
- 保存してあるレシピは書き換えない。表示のときに足す（`src/shared/step-amounts.ts`）。人数を変えれば添える分量も換算され、材料を直せば追従する。AI は使わない
- レシピの画面と料理モード（読み上げも）の両方
- 添えないとき：別の言葉の一部（水気・塩昆布・サラダ油・溶き卵）／手順にもう分量が書いてある（塩小さじ1）／分量の無い材料／同じ手順の2回目以降
- ほかに添えないとき：後ろに分量が書いてある（塩をひとつまみ・水を大さじ2・「酒、みりんを各大さじ1」）／水・油を材料としてではなく使う（水にさらす・油は捨てる）／長い但し書きの分量
- 分量の後ろの但し書き（1枚(300g) の (300g)）は外して添える
- 料理モードのタイマーは、分量を添える前の文から探す
- 添えるのは材料表の分量そのまま。「塩の半量」のように分けて使う手順でも全量が出る（文の「半量」は残る）

## 選ばなかった案
- AI で手順を書き直す → 元の文が変わり、費用もかかる。出典の文を勝手に変えない（DEC-011）
- 取り込みのときに手順へ書き込む → 人数の換算や材料の直しに追従しない
