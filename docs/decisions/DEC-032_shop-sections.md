# DEC-032: 買い物リストを売り場別にし、売り場の並びを家ごとに変えられる

- Status: Accepted
- Date: 2026-11-13
- 決めた人: Eiichi（「よくある売り場別に。並びは自分がスーパーを回る順に並び替えたい。デフォルトは一般的な並びに」）

## 背景
売り場は「野菜・きのこ／肉・魚・卵／その他／調味料」の4つで、判定の辞書も小さかった。
カツオ・ネギ・椎茸・生米・塩昆布・薬味が「その他」に落ち、豆腐や牛乳も「その他」だった。

## 決定
- 売り場は10個。おすすめの並びは日本のスーパーのよくある回り方（入口の青果 → 奥の鮮魚・精肉 → 日配 → 加工食品 → 冷凍・飲料）：
  野菜・果物 → 魚 → 肉 → 卵・豆腐・乳製品 → 調味料 → 乾物・缶詰 → 米・パン・麺 → 冷凍食品 → 飲み物 → その他
- 判定は `src/shared/ingredients.ts` の規則を上から順に当てる。順番に意味がある（「鶏がらスープの素」は肉より先に調味料、「かつお節」は魚より先に乾物、「牛乳」は肉より先に乳製品、「冷凍えび」は魚より先に冷凍）。AI は使わない
- 並びは家（グループ）ごとに `groups.shop_order` に保存。2人で同じ店を回る前提で共有する。null ならおすすめの並び
- 並び替えは ↑↓ のボタン（ドラッグにしない。片手で確実に押せて、読み上げでも使える）
- 後から売り場が増えたら、保存した並びの「おすすめで1つ前の売り場」のすぐ後ろに入る

## 選ばなかった案
- 人ごとの並び → 買い物リストは2人で共有。別々の店に行くことが増えたら見直す
- 店ごとの並び（店を選ぶ）→ 今は1つで足りる。迷ったらシンプルな方
- 売り場を自分で作る・名前を変える → 判定の規則と合わなくなる

## 影響
- 「いつも家にある扱いの調味料」（買い物リストで最初から隠れる・冷蔵庫に入らない・おすすめの材料に数えない）は、売り場とは別に今までどおり決まった一覧（SEASONINGS）だけ。売り場が「調味料」でも、パン粉・白だし・ウスターソースなどは買うものとして出る（isStapleCanonical）
- 名寄せ（ネギ → 長ねぎ など）は増やしていない。冷蔵庫に入っている名前とずれて、二重に入るのを避けるため。表記ゆれは売り場の判定の側で拾う
- 売り場の判定は同じ名前で何千回も呼ぶので、名前ごとに覚えておく（Workers の CPU 10ms に収める）
