# DEC-034: 冷蔵庫のまとめて移動・並べ替え・元に戻す

- Status: Accepted
- Date: 2026-11-17
- 決めた人: Eiichi（「冷凍に移動させたりするから、まとめて移動にしたい」「全部の並び替え。ソートでも、期限でも、手で入れ替えでも。間違って自動ソートしたときの戻るも」）
- 関連: DEC-033（冷蔵庫の仕分け）

## 決定
- **まとめて移動**：選ぶチェック（これまで「レシピを探す」用）で選び、「まとめて移動」から室を選ぶ。選べるのは50個まで（レシピを探すのは今までどおり10個まで）
- **冷凍室への移動はその品だけ**（`pantry_items.zone`）。冷凍は「今回だけ冷凍した」ことが多く、次に買った豚こままで冷凍室に入ると困るため。ほかの室への移動は DEC-033 どおり名前ごとに覚える（`pantry_zone_prefs`）。いつもの室に戻したら覚えた分は消す。規則は `planZoneMove` 1つにまとめる
- **並べ替え**：室の中の並びは 期限が近い順（はじめ）／入れた順／名前順／手で並べた順。家で1つ（`groups.fridge_sort`）。室の上下の順番も変えられる（`groups.fridge_zones`。常温はいつも最後）
- **手で並べる**：↑↓ で室の中の順番を変え、「この並びにする」で保存（`pantry_items.position`）。手で並べた順は、ほかの並べ方にしても消えない。後から入った品は手で並べた品の後ろに期限が近い順で出る
- **元に戻す**：まとめて移動・並べ方の変更・手で並べたあとに、6秒「元に戻す」を出す。移動は API が移す前の状態（undo）を返し、それを送り返して戻す

## 選ばなかった案
- 冷凍室への移動も名前ごとに覚える → 冷凍は一時的なことが多い。いつも冷凍する品は、その都度まとめて移せば足りる
- 手で並べるときのドラッグ → ↑↓ のボタン（片手で確実・読み上げで使える）。DEC-032 と同じ
- 「元に戻す」を何段も → 直前の1回で足りる。迷ったらシンプルな方

## 影響
- 元に戻す（/pantry/restore）は自分の家の品だけ書き換える。名前ごとの置き場所も家ごと。漏れのテストは test/api/fridge-arrange.test.ts
