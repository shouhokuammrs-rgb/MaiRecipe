# DEC-021: 料理モードに「お料理アシスタント」を入れる（相談は AI・無料枠）

- Status: Accepted
- Date: 2026-10-20
- 決めた人: Eiichi
- 関連: DEC-012 / DEC-018 / Issue #26

## 背景
料理モード（手順・タイマー・読み上げ・声で「次」）は AI なしで動く。
Eiichi の希望：「次読んで」「タイマー」だけでなく、「砂糖大さじ1って小さじ何杯？」のように色々相談できる相手にしたい。

## 決定
- **すぐ動く言葉**（次・戻って・次読んで・手順3・5分のタイマー…）は端末だけで動かす（AI なし・すぐ）
- **相談は「ねえ、〜」と話しかけたときだけ**聞く。台所の普通の会話を拾って勝手に答えないため。画面の「相談」からは文字・マイクでも聞ける
- **計量の換算**（大さじ・小さじ・カップ・ml）は AI を使わず計算で答える。答えに「計算した答え」と出す
- ほかの相談は AI（Gemini の無料枠。だめなら Workers AI）。今のレシピ・今の手順・直前のやりとり（6件まで）を渡し、2〜3文の話し言葉で答えさせる。答えに「AI の答え（間違えることがあります）」と出す
- AI が「タイマーをかける」「手順3へ」と返したときは、その操作もする（形を決めた JSON だけ受け付ける）
- レシピはサーバーがセッションのグループから読む（クライアントが送ったレシピ本文は使わない）。相談の中身は保存しない
- 相談は人が聞いたときだけ AI を呼ぶので、DEC-012 の「押した時だけ」に沿う。無料枠のあいだは費用はかからない

## 影響
- 一般公開するときは、無料枠が全員で共有になるので、有料プランの機能にするか回数を決める
- 声での相談は、端末の音声認識に頼る（iPhone のホーム画面アプリでは画面を点けておく必要がある）
