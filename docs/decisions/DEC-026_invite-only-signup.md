# DEC-026: 新しいアカウントは、招待された人だけ作れる

- Status: Accepted
- Date: 2026-10-23
- 決めた人: Eiichi（改善の提案 3 を「進めよう」）
- 関連: DEC-009（Google ログインのみ）/ DEC-025（AI の使用量はアプリ全体で1つ）/ #14 招待

## 背景
Google アカウントがあれば誰でもログインでき、その人だけの空のグループができていた。
2人のデータは見えないが、AI の無料分はアプリ全体で1つなので、知らない人に使い切られると2人も使えなくなる。

## 決定
- 新しいアカウントを作れるのは、次のどちらかだけ
  - どこかのグループから招待されているメール（設定の「いっしょに使う人」で招待したもの）
  - まだ誰もいないとき（最初の1人）
- すでにアカウントのある人は、今までどおりログインできる
- 断ったときはログイン画面に「招待された人だけが使えます。使っている人に招待してもらってください」
- ローカル開発・テスト（DEV_LOGIN=1）だけは誰でも作れる（本番には DEV_LOGIN を入れない）
- 仕組み：Better Auth の `databaseHooks.user.create.before` で `canSignUp`（src/api/data/membership.ts）を確かめる。メールアドレスの一覧を設定に持たない

## 影響
- 一般公開（M5）のときは、招待制をやめて、グループごとの AI の上限に切り替える
