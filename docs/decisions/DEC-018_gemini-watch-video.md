# DEC-018: 手順が文字で書かれていない動画は、Gemini（無料枠）に動画そのものを見せて読む

- Status: Accepted
- Date: 2026-10-19
- 決めた人: Eiichi
- 関連: DEC-012 / DEC-016 / DEC-017 / Issue #36

## 背景
料理動画は、概要欄に材料だけ書いて、手順は動画の中で話すだけのものが多い（例：コウケンテツさんのカオマンガイ）。
文章を読む AI（Workers AI・DEC-016）は、書かれていない手順を作らない決まりなので、手順が 0 のままになる。
Gemini API は YouTube の URL をそのまま渡すと、動画の音声と映像から内容を読める。無料枠があり、カードの登録も要らない。

## 決定
- 動画の取り込みで、規則で材料か手順が 0 のときは、**鍵（GEMINI_API_KEY）があれば Gemini に動画を見せる**（概要欄を手がかりとして添える）
- 材料が概要欄から読めていれば、**材料は概要欄（投稿者が書いた分量）を、手順は Gemini のものを使う**
- Gemini が失敗したら、文章を読む AI（Workers AI）に回す。どちらも駄目なら規則の結果に理由を添える（DEC-017 と同じ）
- 使うのは無料枠だけ（モデルは `src/api/ai/` の表の1行。今は gemini-3.8-flash）。画は粗い設定（MEDIA_RESOLUTION_LOW）で使う量を減らす
- 鍵は Eiichi 個人のもの。`wrangler secret`（ダッシュボードのシークレット）にだけ置き、使うのは `src/api/platform/gemini.ts` だけ
- 無料のあいだは DEC-017 の「自動」の例外に含める。Gemini を有料にするときは「押した時だけ」に戻す

## 影響
- 動画の取り込みは 30 秒〜1 分かかることがある（画面に目安を出す）
- Gemini の無料枠では、送った内容が Google のサービス改善に使われることがある。送るのは公開動画の URL と、その動画の概要欄だけ
- 非公開・限定公開の動画は読めない（規則の結果に戻る）
- 一般公開するときは、無料枠が全員で共有になるので見直す
