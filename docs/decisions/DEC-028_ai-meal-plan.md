# DEC-028: 保存しているレシピから、AI に献立を考えてもらう（選んだものだけ入れる）

- Status: Accepted
- Date: 2026-10-25
- 決めた人: Eiichi（「どんどん進めちゃって」。#15 の3つ目）
- 関連: DEC-010（取り込み → 改良 → 献立 → 買い物）/ DEC-012（AI は押した時だけ・出典を分ける）/ DEC-025（使用量の見張り）/ #15

## 背景
献立は毎回、レシピ一覧から1品ずつ選んで入れていた。冷蔵庫の期限が近い食材や、最近作ったものを見ながら何日分も組むのは手間がかかる。

## 決定
- 献立の画面に「AI に献立を考えてもらう（無料）」。押した時だけ動く。何日分（今日だけ／3日分／1週間分）・どの食事・希望（任意・100字まで）を選ぶ
- **使うのは自分たちが保存したレシピだけ**。新しいレシピは作らせない（作るのは別の機能で、「出典なし（AI）」と分けて見せる）
- AI にはレシピを**番号で**渡す（id は渡さない）。返ってきた番号を API 側でレシピに戻し、知らない番号・頼んでいない日や食事・同じ枠の2つ目は捨てる。1食は3品まで
- 一緒に渡すのは、レシピの名前・分類・ジャンル・主な材料（最近のもの 80 件まで）、冷蔵庫の中身（期限が近いかどうか）、過去7日に作ったもの、もう入っている献立。どれもグループの中から読む
- 案は画面に出すだけで保存しない。人が選んだ品だけ、今までの「献立に入れる」で1品ずつ入れる（最初は全部選んである）
- Gemini が使えなければ Workers AI。使用量は DEC-025 の見張りを通す（`gemini:plan_suggest`・`workers-ai:plan_suggest`、それぞれ1日20回）

## 影響
- レシピが無いときは「先にレシピを保存してください」（422）。AI の鍵が無いときは今までどおり手で入れる
- 一般公開（M5）で AI を有料にするときは、この機能もプランで分ける
