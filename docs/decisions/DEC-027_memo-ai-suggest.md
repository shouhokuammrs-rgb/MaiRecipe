# DEC-027: メモから、AI に変更案を出してもらう（選んだものだけ版にする）

- Status: Accepted
- Date: 2026-10-24
- 決めた人: Eiichi（「6はやりたいかも」）
- 関連: DEC-012（AI は押した時だけ）/ DEC-013（版とメモ）/ DEC-025（使用量の見張り）/ #23

## 背景
「次は砂糖控えめ」のようなメモを書いても、それを材料・手順に直すのは手作業だった。
#23 は「自分の Anthropic API キーで」としていたが、今は AI を無料枠（Gemini・Workers AI）で使っている（DEC-016・018）。

## 決定
- 「メモをレシピに反映」の画面に「AI に変更案を出してもらう（無料）」。押した時だけ動く
- AI には今の最新版とメモだけを渡す（グループの中から読む。画面の送った本文は使わない）
- 返事は「材料を変える・消す・足す／手順を変える・消す・足す／コツを足す」の変更案の一覧。番号と中身を API 側で確かめ、変わらない案・読めない案は捨てる
- 案ごとに、メモのどの言葉から出たか（quote）を付けさせ、**その言葉が本当にメモにあるかを照らし合わせる**。
  あれば「メモより」、無ければ「AI の推測（メモには無い）」として分けて見せる
- メモに基づく案だけ最初から選んでおく。AI の推測は人が選んだときだけ入れる
- 選んだ案は編集欄に入るだけ。人が確かめて保存すると、今までどおり「メモを反映した版」になる
- Gemini が使えなければ Workers AI。使用量は DEC-025 の見張りを通す（`gemini:memo_apply`・`workers-ai:memo_apply`）
- #23 の「自分の API キー」「プレミアム」の設定は作らない（無料枠で足りているため。公開のときに見直す）

## 影響
- 一般公開（M5）で AI を有料にするときは、この機能もプランで分ける
