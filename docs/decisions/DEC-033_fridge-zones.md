# DEC-033: 冷蔵庫の中を室ごとに分けて見せる。置き場所を直すと名前ごとに覚える

- Status: Accepted
- Date: 2026-11-17
- 決めた人: Eiichi（「冷蔵庫の中も仕分けしたい。冷蔵庫の中をイメージした感じで」）
- 関連: DEC-032（買い物リストの売り場）

## 決定
- 室は6つ。冷蔵庫の上から：冷蔵室 → チルド → ドアポケット → 野菜室 → 冷凍室。常温（じゃがいも・玉ねぎ・米・缶詰など）は冷蔵庫の外の棚として最後に出す
- 置き場所は名前から決める（`fridgeZone`。売り場の判定を下敷きにする。AI は使わない）：
  肉・魚 → チルド／野菜・果物 → 野菜室（じゃがいも・玉ねぎ・さつまいも・かぼちゃ・バナナ・ごぼうは常温）／卵・豆腐・乳製品 → 冷蔵室（牛乳・豆乳はドアポケット）／飲み物・たれ → ドアポケット／冷凍 → 冷凍室／乾物・缶詰・米・乾麺・パン → 常温（ゆで麺・生麺は冷蔵室）
- 編集シートで置き場所を直せる。直した置き場所は食材の名前ごとに家で覚える（`pantry_zone_prefs`）。使い切って消えても、次に同じ名前が入るとその室に出る。「おまかせ」に戻すと名前から決める
- 画面は冷蔵庫の形：本体の枠の中に室を並べ、野菜室・冷凍室は取っ手のある引き出しにする。空の室も「空いています」で出す（どこに何が無いかも分かる）

## 選ばなかった案
- 食材の行に置き場所を持たせる → 使い切ると消えるので、毎回直すことになる
- 室の並びを家ごとに変える（真ん中が野菜室か冷凍室か）→ 今は上の順で足りる。声があれば DEC-032 と同じ仕組みで足す
- 室を自分で作る → 迷ったらシンプルな方

## 影響
- 新しい表 `pantry_zone_prefs` は forGroup の中だけで読み書きする。漏れのテストは test/api/fridge-zones.test.ts
