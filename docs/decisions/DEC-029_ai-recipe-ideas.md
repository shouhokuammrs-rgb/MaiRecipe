# DEC-029: 冷蔵庫の食材から、AI に新しいレシピを考えてもらう（出典なしとして分ける）

- Status: Accepted
- Date: 2026-10-25
- 決めた人: Eiichi（「どんどん進めちゃって」。#15 の2つ目）
- 関連: DEC-011（取り込みと出典）/ DEC-012（AI は押した時だけ・出典あり / なしを分ける）/ DEC-025（使用量の見張り）/ DEC-028（AI の献立）/ #15

## 背景
冷蔵庫で食材を選ぶと、保存しているレシピから使うものを探せる。でも保存しているレシピに合うものが無いと、そこで止まっていた。

## 決定
- 冷蔵庫で食材を選んで「レシピを探す」を押すと、保存しているレシピの下に「AI に新しいレシピを考えてもらう（無料）」が出る。押した時だけ動く。希望（任意・100字まで）も書ける
- AI には選んだ食材と、冷蔵庫のほかの食材（30個まで・使わなくてよい）だけを渡す。どちらもグループの中から読む
- 違う料理を3つまで。分類・ジャンルは決まった中から（外れたら「その他」）。材料と手順が無い案は捨てる。保存はしない
- 人が「このレシピを保存する」を押したときだけ保存する。保存したレシピは **`origin = "ai"`** にして、レシピの画面に「AI が考えたレシピです（出典なし）。分量や火の通りは確かめてから作ってください」と出す
- 実在のレシピを書き写さないよう、頼む文で決めておく。生焼けの心配がある食材は「中まで火を通す」を手順に書かせる
- Gemini が使えなければ Workers AI。使用量は DEC-025 の見張りを通す（`gemini:recipe_idea`・`workers-ai:recipe_idea`、それぞれ1日20回）

## 影響
- `origin` に `ai` が増える（SQLite の列は text のままなので、マイグレーションは要らない）
- 一般公開（M5）で AI を有料にするときは、この機能もプランで分ける。SNS でレシピを見せるようになったら、AI のレシピは「出典なし（AI）」の印を付けたまま見せる
