# DEC-023: 表紙は、自分の写真が無ければ出典の画像を「元の場所から」表示する

- Status: Accepted
- Date: 2026-10-23
- 決めた人: Eiichi
- 関連: DEC-011（元の写真はコピーしない）

## 背景
表紙は自分で写真を入れる作りで、入れなければ色と絵だけだった。
Eiichi：自分では入れないが、入れられるのは良い。何もしなくても出典の適切な画像が出て、変えることもできるようにしたい。

## 決定
- 表紙の順番：**自分の写真 → 出典の画像 → 色と絵**
- 出典の画像は**こちらに保存しない**（DEC-011 のまま）。URL だけ覚えて、元の場所から表示する（LINE・Slack のリンクプレビューと同じ）
  - 動画：YouTube のサムネイル（i.ytimg.com）
  - サイト：ページの共有用の画像（og:image / twitter:image）。https だけ
- 前に保存したサイトのレシピは、一覧を開いたときに一度だけ出典のページから探して覚える（1回に5件まで）。無ければ「無かった」と覚えて、もう探さない
- 出典の画像を出しているときは、表紙に「画像：〇〇（サイト名）」と出し、元のページへのリンクにする
- 「自分の写真にする」でいつでも変えられる。自分の写真を消すと、出典の画像に戻る
- 出典のサイトに、こちらの URL は渡さない（referrer を送らない）。画像が読めなければ色と絵に戻す

## 影響
- 出典のサイトが画像を消す・変えると、表紙も変わる（こちらでは持っていないため）
- 一般公開・SNS にするときは、他の人に出典の画像を見せてよいか、サイトごとの規約を見直す
