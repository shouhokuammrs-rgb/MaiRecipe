# DEC-013: レシピは版を積み上げ、メモと一緒に「改良のあゆみ」として見せる

- Status: Accepted
- Date: 2026-09-28
- 決めた人: Eiichi
- 関連: docs/spec.md §3・§6

## 背景
取り込んだレシピを作ってみて「米酢のほうがいい」「砂糖を減らす」と気づいたら、材料を直したい。
でも元がどうだったか、どう良くしていったかも残したい。

## 決定
- レシピの中身（材料・手順・名前）は版（recipe_versions）ごとに丸ごと持つ。編集すると新しい版が積まれ、前の版との差分を短い行で残す
- 何も変わっていなければ版を増やさない
- メモ（recipe_memos）は版と同じスレッドに時系列で並べる。メモから直した版は「メモから更新」、どのメモを反映したかを記録する
- 版もメモも消せる（間違えた投稿のため）。元のレシピ（v1）だけは消せない。版を消すと、反映していたメモは未反映に戻る
- 献立・買い物リスト・材料から探すは、常に最新版を使う
- 画面では「改良のあゆみ」は普段閉じておき、開くとスレッドで流れが読める

## 影響
- 将来の SNS の「アレンジ（他人のレシピを自分用に派生）」は、この版の仕組みの延長で作れる
