# DEC-024: コツ・ポイントを手順とは別に持ち、グループの中だけで見る

- Status: Accepted
- Date: 2026-10-23
- 決めた人: Eiichi（「コツも残して、手順のところに出して」）
- 関連: DEC-011（取り込みは材料と手順だけ）/ DEC-021（料理アシスタント）

## 背景
サイトの「コツ・ポイント」欄や、動画で話している「ここがポイント」は、作るときにいちばん役に立つ。
今までは DEC-011 に従い、コツの欄の手前で読むのをやめて捨てていた。

## 決定
- レシピの版に `tips`（`{step, text}[]`、最大8件・1件150字）を持つ。`step` はどの手順のコツか（1始まり）、全体のコツは null
- 取り込み
  - ページ：「コツ・ポイント」などの見出しの後の文を、行ごとに1件にする。「手順3で」「③の」と書いてあればその手順に付ける。
    構造化データが取れた後も、コツの欄を探して最大 150KB だけ読み進める（無料プランの CPU のため上限つき）
  - AI（動画を見る・本文を読む）：コツを「自分の言葉で40字くらい」にまとめて、手順の番号つきで返させる
- 表示：詳しい画面では手順の下に「コツ：…」、全体のコツは作り方の後。料理モードではその手順のところに出し、読み上げでも続けて読む。アシスタントにも渡す
- 編集画面で直せる。コツは手順の行に付けるので、並び替え・削除してもずれない
- **コツは出典の文をそのまま持つことがあるので、自分たち（グループ）だけが見るメモとして扱う。将来 SNS で公開するときは出さない**（DEC-011 の「元の文章はコピーしない」は公開の話として守る）

## 影響
- 公開機能（M5）を作るときは、公開する版から `tips` を外す
- 構造化データのあとを読み進める分、取り込みの CPU が少し増える。上限に当たったら Eiichi に相談する（DEC-008）
