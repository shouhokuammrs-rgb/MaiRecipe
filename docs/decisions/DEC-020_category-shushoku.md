# DEC-020: カテゴリの「丼」を「主食」（ご飯・麺・パン）にまとめる

- Status: Accepted
- Date: 2026-10-19
- 決めた人: Eiichi

## 背景
カテゴリ（主菜 / 副菜 / 汁物 / 丼 / デザート / その他）は MECE でなかった。
「丼」だけ軸が違い（役割ではなく形）、「主食」が無いのでパスタ・うどん・パン・炊き込みご飯の行き場が「その他」か「丼」しかなかった。

## 決定
- カテゴリは **主菜 / 副菜 / 汁物 / 主食 / デザート / その他**。丼は主食に含める
- 保存済みの「丼」はマイグレーション（0005）で「主食」に移す（レシピと版の両方。件数は変わらない）
- 古い画面から「丼」が来ても受け取り、主食として保存する
- 今日のおすすめでは、主食は今の丼と同じく「主菜」の枠に入れる
- ジャンル（和食 / 洋食 / 中華 / 韓国 / エスニック / その他）はそのまま。韓国はエスニックの一部だが、よく作るので分けておく
