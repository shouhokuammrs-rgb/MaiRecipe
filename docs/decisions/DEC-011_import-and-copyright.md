# DEC-011: 取り込みは材料と手順だけを取り出し、出典は消せないようにする

- Status: Accepted
- Date: 2026-09-28
- 決めた人: Eiichi
- 関連: docs/spec.md §3 / 旧 ISS-001

## 背景
URL から取り込んだレシピを、将来 SNS で改良版として公開したい。2026-09 時点で調べた範囲では、
レシピの材料・手順はアイデアや事実として著作権の保護対象外とされる一方、元の文章表現と写真には著作権がある。
YouTube の公式埋め込みは、動画の送信元が元のサイトなので侵害にならないとした判決がある（違法アップロードを除く）。
（Eiichi は弁護士ではない。公開前に専門家に確認する）

## 決定
- 取り込みは schema.org の Recipe（JSON-LD）から、材料と手順だけを取り出す。元の写真はコピーしない
- 動画は YouTube の公式埋め込みで再生する。動画ファイルは保存しない
- 取り込んだレシピの出典（source_url）は編集で変えられない。版を積んでも元のレシピ（v1）は消せない
- 取り込みに AI は使わない。読めないページは出典を残したまま手で入れる

## 影響
- 公開するときは、出典リンクと動画の埋め込みを必ず表示する
- サイトの利用規約で転載を禁じているところは、著作権とは別に公開の可否を決める（公開時に取り込み元ごとに判断）
