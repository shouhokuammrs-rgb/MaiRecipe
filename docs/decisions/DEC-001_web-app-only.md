# DEC-001: Web アプリとして開発し、モバイルネイティブアプリは作らない

- Status: Accepted
- Date: 2026-09-02
- 決めた人: Eiichi
- 関連: docs/spec.md §4

## 背景

レシピ管理は外出先のスマホでも自宅の PC でも使いたい。
ただしネイティブアプリはストア審査・端末別の実装・配信の手間が大きく、
学習と制作を目的とした個人プロジェクトには重すぎる。

## 決定

Web アプリのみを作る。スマホではブラウザで使う。

## 検討した別案と、選ばなかった理由

- 案B: React Native / Expo でネイティブアプリ → ストア審査と配信の手間、学習コストが目的に見合わない
- 案C: Web + ネイティブの両方 → 個人で二重メンテナンスは現実的でない

## 影響

- ユーザーはブラウザのブックマークやホーム画面追加でアクセスする
- レスポンシブ対応（スマホ縦・PC）が必須になる
- PWA 化は M3 以降に検討の余地を残す
