# DEC-004: データはクラウド保存にし、所有の単位をユーザーではなくグループにする

- Status: Accepted
- Date: 2026-09-02
- 決めた人: Eiichi
- 関連: docs/spec.md §6 / DEC-001

## 背景

スマホで見つけたレシピを保存して、PC で献立を組み、買い物中にスマホで買い物リストを見る、という使い方をしたい。
端末ごとにデータが分かれていると成立しない。
また将来パートナーとの共同管理を入れる予定があり、後からデータの持ち主を付け替えるのは移行が重い。

## 決定

データはクラウド（Supabase Postgres）に保存し、同じアカウントでログインすればどの端末でも同じデータが見えるようにする。
ユーザー所有物は個人ではなく**グループ**に紐付ける。個人利用時は本人1人だけのグループになる。

## 検討した別案と、選ばなかった理由

- 案B: 端末内保存 + 手動エクスポート → 複数端末で使えず、作りたかった体験にならない
- 案C: まず個人所有で作り、共有機能を入れるときに移行する → データ移行とアクセス制御の作り直しが発生する

## 影響

- 同じアカウントでログインすれば、どの端末でも同じレシピ・献立・買い物リストが見える
- 全テーブルのアクセス制御はグループ所属を基準にする（RLS）
- 共有機能そのものは M4 まで実装しないが、スキーマは最初からグループ基準で作る
