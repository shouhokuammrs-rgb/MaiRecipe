# DEC-002: 差別化を狙わず、レピッタの機能構成をそのまま踏襲する

- Status: Accepted
- Date: 2026-09-02
- 決めた人: Eiichi
- 関連: docs/spec.md §2 / docs/spec.md §4

## 背景

このプロジェクトの目的は新規サービスの成功ではなく、Eiichi の学習と制作。
独自機能を考える時間は、作りきる時間を圧迫する。
参考にするレピッタ（repitta.com）は機能セットが既に整理されている。

## 決定

レピッタの機能構成を踏襲する。独自の差別化機能を提案・実装しない。
機能を採用するかの第一基準は「レピッタにあるか」。

## 検討した別案と、選ばなかった理由

- 案B: 独自機能で差別化する → 目的が学習なので、仕様検討に時間を使う価値が低い
- 案C: 機能を絞った最小版だけ作る → 献立から買い物リストまで通らないと、作りたかった体験にならない

## 影響

- 仕様で迷ったときは「レピッタはどうしているか」を先に確認する
- 新しいアイデアが出ても、原則 Issue に `idea` ラベルで置くだけにする
- 将来公開して収益化を目指すことになったら、この判断を見直す
