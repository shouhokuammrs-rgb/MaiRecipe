# DEC-012: AI は既定オフ。押した時だけ動き、答えは出典あり / なしを分ける

- Status: Accepted
- Date: 2026-09-28
- 決めた人: Eiichi
- 関連: docs/spec.md §3（M4）/ DEC-006

## 背景
AI が裏で動き続けると費用がかかり、何をしたのか分かりにくい。ハルシネーションも心配。

## 決定
- AI が無くても全部の機能が使える。AI は人が楽をするための上乗せ
- AI が動くのはボタンを押した時だけ（メモをレシピに反映、AI で読み直す など）
- 個人利用は自分の Anthropic API キー（`wrangler secret`）。一般公開したら AI 機能はプレミアムプランだけ
- AI の答えは文ごとに「出典あり（レシピの版・メモ・献立・動画の説明）」と「出典なし（AI の知識・推測）」に分けて表示する。
  出典の番号と引用が本当に資料にあるかを API 側で照合し、合わなければ「出典なし」に落とす

## 影響
- M0〜M3 は AI を使わない。AI は M4 で入れる
- 料理モード・お料理アシスタント（料理中の質問）は、見た目を詰め直してから相談する（spec.md §4）
