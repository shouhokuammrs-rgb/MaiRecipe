# DEC-015: YouTube は公式 API のコメントまで読む。字幕・音声は取らず、動画は Gemini に見せる（無料枠は2人の間だけ）

- Status: Accepted
- Date: 2026-09-29
- 決めた人: Eiichi
- 関連: DEC-011 / DEC-012 / DEC-014（拡張）/ Issue #36 / docs/spec.md §3（#7）

## 背景
概要欄に材料を書かず、コメント（多くは投稿者本人の固定コメント）に書くチャンネルがある。
概要欄にもコメントにも無い動画では、中身を見ないと材料が分からない。
字幕や音声を取れば読めるが、YouTube が公式に出している方法ではない。

## 決定
- **コメントから読む（DEC-014 を拡張）**：概要欄とそこに貼られたリンクで読めなかったときだけ、
  YouTube Data API の commentThreads（関連度順）を同じキーで取り、概要欄と同じ読み方で1件ずつ試す。AI は使わない
  - 固定コメントかどうかは API で見分けられないので、**投稿者本人のコメント**を先に、次に他の人の上位5件を読む
  - コメントに貼られたリンクは投稿者本人のものだけたどる（他の人のリンクは宣伝のことがある）
  - 取れたら出典は動画の URL。取り出すのは材料と手順だけ（DEC-011）
- **非公式の字幕取得・音声ダウンロードは採用しない**：YouTube の利用規約に反するため
- **動画の中身から読むときは Gemini API に YouTube の URL を渡す**（#36 の「動画を見て読み取る」。押した時だけ・既定オフ、DEC-012）
  - Gemini の無料枠は、送った内容が Google の学習に使われる。そのため無料枠を使うのは **Eiichi とパートナーの2人で使う間だけ**。
    **一般公開するときは有料枠に切り替える**

## 検討した別案と、選ばなかった理由
- 字幕を非公式に取って規則で読む → 規約違反。YouTube 側の変更ですぐ壊れる
- 音声をダウンロードして文字起こし → 規約違反。Worker の無料プランでは処理も重い
- 視聴者のコメントのリンクもたどる → 宣伝・スパムのページを取り込むおそれがある
- 最初から Gemini の有料枠を使う → 2人で使う間は無料枠で足り、送るのは公開動画の URL だけ

## 影響
- ユーザーには：コメントにレシピがある動画でも材料と手順が入り、「動画のコメントから読み取りました（AI なし）」と出る
- 運用：コメントの取得は1回あたり1ユニット。概要欄で読めなかったときだけ呼ぶので、無料枠（1日1万ユニット）への影響は小さい
- 視聴者が書いた誤ったレシピを拾うことがある（本人のコメントを先に読むことで減らす）。保存前に画面で確かめる流れは今のまま
- 見直すとき：一般公開する前。Gemini を有料枠に切り替え、YouTube のキーの扱い（DEC-014）と合わせて新しい ADR を書く
