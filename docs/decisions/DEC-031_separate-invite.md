# DEC-031: 別々に使う人も招待できる（グループには入れない）

- Status: Accepted
- Date: 2026-11-09
- 決めた人: Eiichi（「母も使えるようにしたい。いっしょに使う人ではなく、母は母で」）
- 関連: DEC-026（招待制）/ DEC-004（グループ）

## 背景
DEC-026 で、新しいアカウントを作れるのは「グループに招待された人」だけにした。
家族や友だちに「自分のレシピ帳として」使ってもらいたいとき、グループの招待しか口がないと、
相手の画面に「参加する」が出て、押すと同じ冷蔵庫・献立になってしまう。

## 決定
- 設定に「別々に使う人を招待」を足す。入れたメールの人は、Google でログインすると自分だけの空のグループで始まる
- 表は `signup_passes`（招待した人 × メール）。グループには触れないので forGroup の外、`src/api/data/membership.ts` に置く（DEC-026 の canSignUp もここ）
- 1人が招待できるのは5人まで。一覧に出るのは自分が入れたメールだけで、相手が使い始めたかだけ分かる
- ログインする前なら取り消せる。使い始めた人は取り消しても消えない（アカウントは本人のもの）

## 選ばなかった案
- 招待制をやめて誰でもログインできるようにする → 公開前に知らない人が入れて、AI の無料枠（アプリ全体で1つ）を使い切られる
- グループの招待で入れて「参加は押さないで」と伝える → 初見の人は押す

## 影響
- AI の無料枠は招待した人も含めて分け合う。一般公開（M5）でグループごとの上限に切り替える
