# DEC-016: 「AI で読み取る」は Workers AI の無料枠で動かす（鍵不要・ふたりで使う間）

- Status: Accepted
- Date: 2026-10-19
- 決めた人: Eiichi
- 関連: DEC-012（AI は押した時だけ）/ DEC-011 / DEC-015 / Issue #36

## 背景
規則（AI なし）で読めない書き方のサイトや概要欄がある。早く AI で補いたい。
Claude は鍵と費用が要る。Cloudflare の Workers AI は無料プランのまま、鍵なしで1日 10,000 ニューロンまで使える（1回約 90）。

## 決定
- 規則で読めなかった取り込みと、貼った文章が分けられなかったときだけ「AI で読み取る（無料）」ボタンを出す。押した時だけ動く（DEC-012）
- モデルは `@cf/openai/gpt-oss-120b`。比べる評価は後回しにし、まず使いながら精度を見る
- AI の呼び出しは `src/api/ai/`（窓口・作業名 `read_recipe`）と `src/api/platform/workers-ai.ts` だけ。モデルの入れ替えは窓口の表の1行
- AI が返した材料名が元の文に無ければ、消さずに「要確認」として画面で知らせる（捏造対策）
- 無料枠を超えると Cloudflare 側でエラーになる（請求は起きない）。そのときは「今日の無料分を使い切りました」と出す
- テストは本物の AI を呼ばない（`remoteBindings: false` と `env.AI` の差し替え）

## 後回し
- 使用量を D1 に記録して、無料枠の9割で規則だけに切り替える見張り（利用が増えたら）
- 動画を見て読み取る（Gemini・DEC-015）
- 一般公開するときは有料プランの機能にする（Workers 有料プランで1回約 0.15 円の見込み）
