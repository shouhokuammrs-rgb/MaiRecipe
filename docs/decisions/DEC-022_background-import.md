# DEC-022: URL の取り込みは裏で進める（Cloudflare Workflows・無料プラン）

- Status: Accepted
- Date: 2026-10-20
- 決めた人: Eiichi
- 関連: DEC-008 / DEC-018 / DEC-019

## 背景
DEC-019 で「正確さ優先・一発で」にした結果、長い動画（15分ほど）は Gemini が動画を見るのに 1〜3 分かかる。
スマホで画面を開いたまま3分待つのはつらく、待っているあいだに画面を閉じると読み取りも止まってしまう。

## 決定
- 「読み取る」を押したら、すぐ返す。読み取りは **Cloudflare Workflows** が裏で進める
  - 無料プランでも使える。1つの手順の待ち時間に上限がない（CPU は 10ms まで。待つ時間は数えない）
  - 読み取りは1回だけやり直す。それでもだめなら「読み取れませんでした」にする
- 状態は D1 の `import_jobs` に残す（読み取り中 / 読めた / 読めなかった）。読めた中身は保存前の下書き（材料と手順だけ。DEC-011）
- 画面
  - 取り込み画面に「読み取りの様子」の一覧。読めたら「確かめる」、読めなかったら「手で入れる」（出典は残す）
  - ほかの画面の下に知らせ（読み取り中… / 読み取れました → 確かめる）
  - 保存した・消した読み取りは一覧から消す。1日たったものは出さない
- グループはセッションから決めて Workflow に渡す。Workflow はそのグループの repo（forGroup）でだけ書く
- 同時に読み取れるのはグループごとに5件まで。10分以上止まったものは「読み取れませんでした」として出す
- すぐ返す `POST /api/import` は残す（テスト・将来のアプリ用）

## 影響
- 通知は画面の中だけ（アプリを閉じているときのプッシュ通知はまだ）
- Workflows の無料枠：同時 100 件・状態は 3 日保存。ふたりで使う分には十分
