# DEC-025: AI の使用量を日ごとに数え、無料分の目安の9割で止める

- Status: Accepted
- Date: 2026-10-23
- 決めた人: Eiichi（改善の提案 5 を「やろう」）
- 関連: DEC-012（AI は任意）/ DEC-018（Gemini）/ DEC-021（料理アシスタント）/ #36

## 背景
AI は Workers AI と Gemini API の無料枠だけで使っている。会社側の上限に当たってもお金はかからないが、
取り込みで使い切ると、料理中のアシスタントがその日使えなくなる。どれだけ使ったかも見えなかった。

## 決定
- `ai_usage`（日本時間の日付 × 作業）に回数だけを数える。誰が使ったか・何を読んだかは持たない
  - AI の鍵はアプリ全体で1つなので、グループごとではない。forGroup の外（`src/api/data/usage.ts`）に置く
- 1日の目安（`src/shared/ai-usage.ts`）の9割に達したら、その作業は呼ばない
  - アシスタントは Gemini が止まったら Workers AI に回し、両方止まったら「今日は止めています」
  - 取り込みは AI が止まっても、構造化データ・規則・手入力で続けられる
- 目安は会社の上限より控えめにする（取り込みを少なめにして、アシスタントの分を残す）。会社の上限が変わったら目安を直す
- 回数は呼ぶ前に数える（失敗しても会社側では数えられるため）
- 設定画面に今日の使用量を出す

## 影響
- 有料のプランや自分の鍵（M4）にするときは、目安を金額の上限に置き換える
