# Instruction: M0 プロジェクト初期化・スキーマv1・メール認証
- Phase: M0
- Priority: 🔴
- 関連WBS: M0-4, M0-5, M0-6, M0-7
- 前提: Eiichiが `.env.local` にSupabase URL/anon key/service_role key、Anthropic APIキーを配置済みであること。なければ手を止めてhandoffに書く

## 目的
以降の全マイルストーンの土台を作る。ログインしてデバイスをまたいでも同じデータが見える状態まで。

## 要件

### 1. プロジェクト初期化（M0-4）
- `apps/web` に Next.js 15 / TS strict / Tailwind / shadcn/ui を初期化
- `@supabase/ssr` で `lib/supabase/{client,server,middleware}.ts` を作成
- `middleware.ts` で `(app)` 配下は未ログイン時 `/login` へリダイレクト
- ESLint/Prettier/Vitest/Playwright をセットアップ、`npm run lint / test / e2e` が通る

### 2. DBスキーマ v1（M0-5）
`supabase/migrations/` に以下を作成。全テーブルRLS有効。

```
profiles          id(uuid, auth.users参照), display_name, created_at, updated_at
groups            id, name, plan(text: free|premium|pro, default free), created_at, updated_at
group_members     group_id, user_id, role(owner|member), PK(group_id,user_id)
recipes           id, group_id, title, source_url, source_type(web|photo|manual), image_path,
                  servings(int), memo, category, created_by, created_at, updated_at
recipe_ingredients id, recipe_id, name, amount(text), unit(text), sort_order
recipe_steps      id, recipe_id, body, sort_order
recipe_tags       recipe_id, tag, PK(recipe_id, tag)
meal_plans        id, group_id, date, slot(breakfast|lunch|dinner|other), recipe_id, created_at
shopping_lists    id, group_id, name, created_at, updated_at
shopping_items    id, list_id, name, amount(text), checked(bool), source_recipe_id(null可), sort_order
```

- サインアップ時トリガー: `profiles` 作成 + 個人用 `groups` 作成 + `group_members(owner)` 追加
- RLS方針: `group_members` に自分が含まれる `group_id` の行だけ全操作可。ヘルパー関数 `is_group_member(group_id)` を `security definer` で作る
- `updated_at` 自動更新トリガー
- Storage bucket `recipe-images`（private）。パスは `{group_id}/{recipe_id}/{filename}`。RLSはgroup_member判定
- 型生成して `lib/supabase/database.types.ts` にコミット

### 3. メール認証（M0-6）
- 画面: `/signup`, `/login`, `/reset-password`, `/update-password`
- Supabase Authのメール確認を有効化（confirm email）。確認後 `/` へ
- ログアウトはヘッダーのメニューから
- ログイン後トップ `/`（`(app)/page.tsx`）は「レシピはまだありません」の空状態だけでよい

### 4. Vercel（M0-7）
- `vercel.json` 不要。`apps/web` をルートとしてデプロイできる構成にし、READMEにEiichi向け手順（Vercel連携ボタンを押すレベル）を書く
